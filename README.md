# CampusEats Catalogue

A simple food catalogue web application built using Node.js and Express.js as part of CS543 Tutorial 08.

## Technologies Used

* HTML
* CSS
* JavaScript
* Node.js
* Express.js

## Features

* View all food items.
* View individual food items.
* Add new dishes using a form.
* REST API integration using GET and POST methods.

## How to Run

```bash
npm install
node server.js
```

Open in browser: `http://localhost:3000`
